# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/noah-be/privacy-coach/security/advisories/new) to share the affected version, reproduction steps, and potential impact. Reports will be reviewed before any public disclosure.

Privacy Coach runs its assessment locally in the browser and does not require a backend. A report is still welcome if browser data could leave the device unexpectedly, recommendations could direct users to unsafe resources, or the build and deployment chain could be compromised.
